`main.py` uses only the Python standard library and writes the entry text deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset). The text is a nine-line scene set in a dark kitchen at 3 a.m.: a kettle switches itself off, steam rises from a full mug nobody poured, and the sugar bowl stands open. Nothing is explained — the reader is left holding the question of who was there.
